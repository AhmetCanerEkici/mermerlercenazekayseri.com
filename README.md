# Mermerler Cenaze Kayseri - Web Sitesi Projesi

Bu depo (repository), Kayseri merkezli olarak İç Anadolu bölgesinde ve tüm Türkiye genelinde 7/24 profesyonel cenaze nakil, hazırlık ve defin hizmetleri sunan **Mermerler Cenaze** firmasının kurumsal web sitesi kaynak kodlarını içermektedir.

## 📝 Proje Hakkında

Web sitesi; firmanın sunduğu Kayseri, Sivas, Kırşehir, Nevşehir, Yozgat özel cenaze hizmetleri ile yurt içi/yurt dışı cenaze nakil süreçlerini kullanıcılara aktarmak, zor anlarında ailelerin firmaya 7/24 hızlıca ulaşmasını sağlamak amacıyla geliştirilmiştir.

- **Canlı Site:** [mermerlercenazekayseri.com](https://mermerlercenazekayseri.com)
- **Web Tasarım & Geliştirme:** Ahmet Caner Ekici

## 🚀 Özellikler

*   **7/24 Hızlı İletişim:** Kullanıcıların acil durumlarda telefon veya WhatsApp üzerinden doğrudan iletişim kurabileceği entegrasyonlar.
*   **Bölgesel Hizmet Sayfaları:** İç Anadolu'daki illere özel hizmet detayları ve bilgilendirmeler.
*   **Yurt İçi ve Yurt Dışı Nakil:** Yasal prosedürler ve lojistik süreçlere dair kurumsal bilgiler.
*   **Mobil Uyumlu (Responsive):** Tüm mobil cihazlar, tabletler ve masaüstü ekranlar ile tam uyumlu modern arayüz.

## 🛠️ Kullanılan Teknolojiler ve Altyapı

*   **İçerik Yönetim Sistemi:** WordPress
*   **Dil / Teknolojiler:** PHP, HTML5, CSS3, JavaScript
*   **SEO:** Arama motorlarında "Kayseri cenaze nakil", "Özel cenaze hizmetleri" gibi kelimelerde optimizasyon.
